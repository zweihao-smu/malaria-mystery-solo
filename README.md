# 昏迷的建筑工程师 · 单机模拟课堂版

恶性疟剧本杀的**单机网页版**：你选择 1 个角色，其余 5 个角色由机器人同学自动扮演。无需服务器、无需联网对战，打开网页即可体验多人课堂的协作氛围。

## 与另外两个版本的区别

| 版本 | 目录 | 说明 |
|---|---|---|
| 单机版 | `malaria-mystery-game` | 纯单人闯关，可解锁全部线索 |
| 单机模拟课堂版（本项目） | `malaria-mystery-solo` | 单人 + 5 机器人，按角色权限搜证，有小组动态和排行榜 |
| 多人课堂版 | `malaria-mystery-classroom` | 真多人联网，教师控场，需要服务器 |

## 玩法

1. 选择一个角色（住院医师 / 检验科技师 / 患者家属 / 流行病调查员 / 神经内科会诊医师 / 临床药师）。
2. 每章读完剧情后进入搜证：你只能解锁「公开」线索和本角色专属线索，其余角色的线索由对应机器人去找（小组动态里能看到）。
3. 进入「关键决策」答题：机器人会陆续作答（显示"已作答 x/6"），答完立即看解析，节奏由你控制。
4. 每章小结和终局都有 6 人排行榜（机器人答题正确率 55%–90% 不等，搜证必拿满分）。

## 计分

- 解锁线索：+1 分/条
- 答对题目：+5 分/题

## 运行

```bash
cd malaria-mystery-solo
npm install
npm run dev    # http://localhost:5175
```

打包部署（纯静态，任意静态服务器/对象存储均可）：

```bash
npm run build  # 产物在 dist/
```

## 技术说明

- Vue 3 + Vite，无任何后端依赖
- 机器人引擎在 `src/composables/useRoom.js`：定时器驱动搜证/作答，玩家推进题目时未答机器人会静默补答
- 存档在 localStorage（key: `malaria-mystery-solo-state`），"继续游戏"会重建机器人并快进其进度
- 游戏数据（角色/线索/题目/知识点）与单人版共用 `src/data/gameData.js`
