# 昏迷的建筑工程师 · 单机模拟课堂版

**在线体验：https://zweihao-smu.github.io/malaria-mystery-solo/**

恶性疟剧本杀的**单机网页版**：你选择 1 个角色，其余 5 个角色由机器人同学自动扮演。无需服务器、无需联网对战，打开网页即可体验多人课堂的协作氛围。

## 与另外两个版本的区别

| 版本 | 目录 | 说明 |
|---|---|---|
| 单机版 | `malaria-mystery-game` | 纯单人闯关，可解锁全部线索 |
| 单机模拟课堂版（本项目） | `malaria-mystery-solo` | 单人 + 5 机器人，按角色权限搜证，有小组动态和排行榜 |
| 多人课堂版 | `malaria-mystery-classroom` | 真多人联网，教师控场，需要服务器 |

## 玩法

1. 你固定扮演**住院医师**，其余 5 个角色（家属、检验科技师、流调员、神经科医师、临床药师）由机器人扮演。
2. 每章读完剧情后开始搜证：
   - 🔍 「公开」和住院医师的线索直接解锁（只有这些线索可见）；
   - 🙋 其他角色的线索**不会显示标题**——在"向团队提问"面板点击对应成员，机器人在小组动态里答复并把线索共享给你；每人可问多条，问完为止；
   - 集齐本章全部线索才能进入答题。
3. 答题节奏由你控制，机器人会陆续作答（显示"已作答 x/6"）。
4. **关键抉择影响结局**：
   - 第二章末：确诊检查决策——选错直接进入 💀 Bad Ending（误诊漏诊）；
   - 第三章末：治疗方案决策——选错进入 🔁 再燃结局（第四章走"复燃疑云"剧情），选对则第四章走"随访与康复"，达成 🎉 Good Ending（痊愈出院）。
5. 每章小结和终局都有 6 人排行榜。

## 计分

- 解锁线索：+1 分/条（含提问获得的）
- 答对题目：+5 分/题
- 关键抉择正确：+5 分/次
- 评级按实际走过的路径计算满分（好结局满分 100 = 25 线索 + 65 题目 + 10 抉择）

## 运行

```bash
cd malaria-mystery-solo
npm install
npm run dev    # http://localhost:5175
```

打包部署（纯静态，任意静态服务器/对象存储均可）：

```bash
npm run build  # 产物在 dist/
```

部署到 GitHub Pages（已配置好，vite base 为 `/malaria-mystery-solo/`）：

```bash
npm run build
npm run deploy   # 把 dist 推到 gh-pages 分支
```

## 技术说明

- Vue 3 + Vite，无任何后端依赖
- 机器人引擎在 `src/composables/useRoom.js`：定时器驱动搜证/作答，玩家推进题目时未答机器人会静默补答
- 存档在 localStorage（key: `malaria-mystery-solo-state`），"继续游戏"会重建机器人并快进其进度
- 游戏数据（角色/线索/题目/知识点）与单人版共用 `src/data/gameData.js`
